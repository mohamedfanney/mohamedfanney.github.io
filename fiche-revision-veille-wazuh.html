Ma veille technologique : Wazuh

1. C'est quoi Wazuh ?

Wazuh est une plateforme open source de supervision et d'analyse de sécurité, de type SIEM/XDR. Elle aide à collecter les journaux de sécurité, repérer les comportements suspects et surveiller les vulnérabilités. Ma veille suit Wazuh ; elle ne correspond pas à une installation personnelle du logiciel.

2. Comment fonctionne la veille du portfolio ?

4 sources : Wazuh officiel, GitHub Releases, avis de sécurité GitHub, CERT-FR
↓
GitHub Actions lance un script Python toutes les 6 heures
↓
Les publications sont enregistrées dans un fichier JSON
↓
Le portfolio permet de rechercher, filtrer et lire les détails en pop-up

Les catégories proposées sont : versions, sécurité, fonctionnalités et actualités. Une recherche par CVE, release ou agent permet d'explorer les publications collectées. Le lien vers l'article original permet de vérifier l'information à la source.

3. Pourquoi faire cette veille ?

L'objectif est de suivre les nouvelles versions, les correctifs et les failles concernant Wazuh. Si une alerte est publiée, la démarche est de vérifier les versions touchées, comprendre le risque, lire la recommandation officielle, puis envisager un test en laboratoire avant une mise à jour.

Limite importante : la collecte automatique n'est pas une analyse personnelle. Les commentaires affichés dans les pop-up sont des pistes de réflexion ; une analyse datée et rédigée par moi reste à faire pour chaque publication importante. Il n'y a pas d'alertes e-mail configurées.

5. Questions possibles du professeur

Pourquoi Wazuh ?

Parce qu'il est lié à la cybersécurité, à la supervision et à mon option SISR.

C'est quoi un SIEM ?

Un système qui centralise et analyse des événements et journaux de sécurité pour aider à détecter les incidents.

Que fait GitHub Actions ?

Il automatise l'exécution du script de collecte suivant une programmation, ici toutes les six heures.

C'est quoi JSON ?

Un format de données structurées utilisé ici pour enregistrer le titre, la source, la date, le résumé et le lien des publications.

C'est quoi une CVE ?

Un identifiant public associé à une vulnérabilité de sécurité référencée.

Ta veille détecte-t-elle les attaques sur tes PC ?

Non. Elle suit des informations sur Wazuh. Ce n'est pas un déploiement opérationnel de Wazuh sur mon réseau.

6. À retenir

Collecter automatiquement ≠ analyser automatiquement. Je dois examiner les publications pertinentes et proposer une action argumentée : surveiller, tester ou mettre à jour, sans annoncer un déploiement qui n'a pas été effectué.
