Déploiement Active Directory — domaine esup.local

Projet de virtualisation Windows Server 2019 et d'administration d'un annuaire Active Directory : création du domaine esup.local, gestion d'utilisateurs et de groupes, GPO et premiers contrôles de sécurité.

Fiche HTML de synthèse établie à partir du descriptif du projet déjà publié sur ce portfolio. La documentation PDF d'origine reste le support détaillé, avec ses captures et ses configurations.

1. Objectif et contexte

Le projet porte sur la mise en place d'un environnement d'annuaire centralisé pour organiser les comptes et gérer des règles de sécurité au sein d'un domaine de test.

Objectif : Centraliser les identités d'un domaine de test et structurer sa gestion et ses règles de sécurité.

2. Environnement technique

Plateforme de virtualisationVirtualBox
SystèmeWindows Server 2019
Machine virtuelle4 Go de RAM et 2 vCPU, selon le descriptif du projet
Domaineesup.local, NetBIOS ESUP
OutilsActive Directory, GPO, PowerShell, DNS

3. Réalisation technique

Étape 1

Création de la machine virtuelle

Installation de Windows Server 2019 dans VirtualBox, avec les ressources prévues pour le serveur.

Étape 2

Déploiement du domaine

Promotion du serveur en contrôleur de domaine avec le nom de domaine esup.local.

Étape 3

Organisation de l'annuaire

Création d'unités d'organisation et de groupes ; import d'utilisateurs via des fichiers CSV et PowerShell.

Étape 4

Politiques de sécurité

Mise en place documentée de règles de mots de passe et de verrouillage d'écran par GPO ; le descriptif évoque aussi une authentification à deux facteurs.

Étape 5

Audit et amélioration

Élaboration d'un plan d'audit des événements de sécurité et veille sur Microsoft Defender for Identity.
